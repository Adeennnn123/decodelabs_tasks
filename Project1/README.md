# Project 1 - Data Cleaning and Preprocessing

## Description

This project performs data cleaning and preprocessing using Python in Jupyter Notebook.

The project includes:
- Loading the dataset
- Exploring the data
- Handling missing values
- Removing duplicate records
- Removing outliers
- Creating new features
- Saving the cleaned dataset

## Files

- Project1.ipynb
- Dataset for Data Analytics.xlsx
- Cleaned_Dataset.xlsx

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## How to Run

1. Download or clone this repository.
2. Open `Project1.ipynb` in Jupyter Notebook or VS Code.
3. Keep all Excel files in the same folder.
4. Run all notebook cells from top to bottom.

## Output

The cleaned dataset is saved as:

`Cleaned_Dataset.xlsx`
