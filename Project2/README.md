# Project 2 - Data Analysis

## Description

This project performs data analysis using Python in Jupyter Notebook.

The project includes:
- Loading the dataset
- Exploring the dataset
- Data preprocessing
- Data analysis
- Data visualization
- Finding insights from the data

## Files

- project2.ipynb
- Dataset for Data Analytics(1).xlsx

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## How to Run

1. Download or clone this repository.
2. Open `project2.ipynb` in Jupyter Notebook or VS Code.
3. Keep the dataset file in the same folder.
4. Run all notebook cells from top to bottom.

## Output

The notebook performs data analysis and displays the results through tables and visualizations.
